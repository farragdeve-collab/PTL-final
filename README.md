# PTL — ثلاث نسخ من الموقع

| النسخة | المجلد | الفكرة |
|---|---|---|
| 1 — Chrome (A: حلقة الخدمات) | `v1-chrome/` | داكنة وسينمائية: حروف PTL كروم ثلاثية الأبعاد (Three.js)، حلقة خدمات ثلاثية الأبعاد، نصوص حركية ضخمة |
| 1 — Chrome (B: شبكة صور الخدمات) | `v1-chrome-grid/` | نفس النسخة 1، بس الخدمات في شبكة كروت بالصور بدل الحلقة |
| 2 — Editorial | `v2-editorial/` | فاتحة وتحريرية: صورة تتوسع مع التمرير، رحلة الشحنة أفقيًا، معاينة صور تتبع المؤشر |
| 4 — Final | `v4-final/` | النسخة النهائية المقترحة: Chrome بشبكة الخدمات بالصور + طرق الشحن + كارت «لنبدأ شحنتك» من Globe. اللوجو أبو طيارة أساسي، واللوجو الجديد على الموبايل وأيقونة التاب |
| 3 — Globe | `v3-globe/` | كرة أرضية ثلاثية الأبعاد بمسارات شحن حية من القاهرة، ومسار رحلة يُرسم مع التمرير |

كل نسخة فيها 3 صفحات (الرئيسية، من نحن، تواصل معنا) وبـ 4 لغات: العربية (افتراضي، RTL)، الإنجليزية، الفرنسية، الصينية.

## التشغيل

النسخ تستخدم ES modules، فلازم تتفتح من سيرفر (مش بالضغط المزدوج على الملف):

```bash
cd ptl-3-versions
python3 -m http.server 8000
# افتح http://localhost:8000
```

أي استضافة ثابتة (Netlify / Vercel / cPanel) تشتغل مباشرة: ارفع مجلد النسخة كما هو.

## تعديل المحتوى

- **كل النصوص بكل اللغات** في `_shared/content.js` (نفس المفاتيح في الأربع لغات).
- **أرقام الهاتف والإيميلات وواتساب والخريطة** في آخر نفس الملف (`PTL_CONTACT`). **حاليًا بيانات تجريبية (example.com و 0000)، لازم تتغير قبل الإطلاق.**
- بعد أي تعديل في `_shared/` أو `_src/` أعد البناء:

```bash
python3 _shared/build.py          # كل النسخ
python3 _shared/build.py v2       # نسخة واحدة
```

البناء يحتاج Python 3 مع `jinja2` و Node.js (لقراءة ملف المحتوى).

## الهيكل

```
_shared/content.js     النصوص والترجمات وبيانات التواصل
_shared/core.js        تبديل اللغة، التمرير الناعم، النماذج، الأسئلة، حالة "مفتوح الآن"
_shared/templates/     الهيدر والفوتر والأيقونات والأجزاء المشتركة
_shared/assets/        اللوجو (ملون + نسخة للخلفيات الداكنة) والصور
_src/v1|v2|v3/         قوالب وتنسيقات وسكربتات كل نسخة
v1-chrome/ ...         الناتج الجاهز للرفع
```

## السلوك على الشاشات المختلفة

اتختبرت كل الصفحات على 11 مقاس: من موبايل 320px لحد شاشة 2560px، ومعاهم الموبايل بالعرض والتابلت بالطول وبالعرض.

- **موبايل (أقل من 760px):** حلقة الخدمات ثلاثية الأبعاد في النسخة 1 بتتحول لكروت تتسحب بالصباع. والكرة الأرضية في النسخة 3 بتبقى باهتة ورا العنوان، وبتنور تاني لما تبدأ المناطق.
- **موبايل بالعرض / شاشات قصيرة (أقل من 560px ارتفاع):** النصوص الحركية الضخمة بتتعرض كقائمة عادية، والهيرو بيتصغر عشان يبان كله.
- **تابلت بالطول:** النسخة 3 بتستخدم ترتيب الموبايل (الكرة فوق والنص تحت).
- **شاشات كبيرة (من 1700px):** المقاسات كلها بتكبر بنسبة واحدة عشان التصميم ما يبانش صغير على شاشات 2K و 4K.
- **أهداف اللمس:** كل الأزرار على الموبايل 40px أو أكتر.

## ملاحظات

- نموذج التواصل يفتح واتساب برسالة جاهزة بلغة الزائر (لا يحتاج سيرفر).
- الصور من Unsplash (ترخيص مجاني للاستخدام التجاري) ومحفوظة داخل كل نسخة.
- المكتبات من CDN: GSAP + ScrollTrigger، Lenis، Three.js، topojson (للنسخة 3).
- لو "تقليل الحركة" (Animation effects) مقفول في جهاز الزائر: الأنيميشن اللي بيتحرك مع التمرير بيفضل شغال، والحاجات اللي بتتحرك لوحدها بتقف (الشريط المتحرك، دوران الكرة الأرضية، الحركة الخفيفة للحروف ثلاثية الأبعاد).
- اللوجو: كل ملفات الـ vector في `_shared/assets/`:
  - اللوجو الأساسي (أبو طيارة): `ptl-color.svg` و `ptl-light.svg`، والعلامة لوحدها `mark-color.svg` و `mark-light.svg`.
  - اللوجو الجديد (الكرة الأرضية): `ptl2-color.svg` و `ptl2-light.svg`، والمختصر `ptl2-compact-*.svg`، والعلامة `ptl2-mark-*.svg`.
  - النصوص فيها بخط Montserrat الحقيقي، والرسومات معاد رسمها كمسارات ناعمة. ملفات PNG اللي في الموقع متصدرة منهم.
